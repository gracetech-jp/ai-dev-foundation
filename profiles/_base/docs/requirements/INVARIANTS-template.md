# 不変条件 / negative space（起きてはいけないこと）— 人間確定の固定資産

これは「モデル/設定から導かれる派生的不変条件」（`docs/rules/consistency.md`）とは**別物**。
設計から再生成させない、**人間が確定する** adversarial テストの根拠資産。
各項目は `docs/requirements/` の Tier S/A 要件の `negative_space` と対応づけ、adversarial テストで検証する。

> adversarial テストは実装LLMに生成・マーカー付与させない
> （人間執筆、または実装とは別コンテキストのモデルが要件文面から逆生成し人間レビューを経たもの）。
