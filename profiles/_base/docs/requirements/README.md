# 要件（このサービスの一次要件）

このディレクトリは、このサービスの要件を**人間批准の永続資産**として置く。
CIが緑でも要件が未達なら不合格、を機械判定できる土台。

- 形式・採番・批准・ハッシュの規約: `docs/rules/requirements.md`
- Tier の定義: `docs/rules/tiers.md`
- negative space（起きてはいけないこと）の固定資産: `INVARIANTS-template.md` を複製して埋める
- 新しい要件は `R-000-template.md` を複製し、次の連番で作る（IDは不変・再利用禁止）

## 批准の動線（重要）

- 要件は人間の commit でのみ `status: ratified` になる。**LLM は当ディレクトリを書き込めない**
  （`.claude/settings.json` の deny ＋ フックで機械的に拒否）。
- 要件の下書きは保護外のスクラッチに出し、人間が中身を確認してからここへ移して批准する。
