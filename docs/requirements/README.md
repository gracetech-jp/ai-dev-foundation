# 要件（この基盤リポジトリ自身のガバナンス要件）

このディレクトリは `ai-dev-foundation` **自身**の一次要件を、人間批准の永続資産として置く。
基盤はアプリを持たないが、「基盤が保証すると約束したガバナンス（破壊的操作の機械遮断など）」を
要件化し、シェルテスト（`tests/*.bats`）で検証することで、**基盤が自ルールを dogfood** する。

- 形式・採番・批准・ハッシュの規約: `docs/rules/requirements.md`
- Tier の定義: `docs/rules/tiers.md`
- 要件は人間の commit でのみ `status: ratified` になる（LLM は当ディレクトリを書き込めない）。
