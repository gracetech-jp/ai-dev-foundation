## 運用ルール

- 1決定 = 1ファイル。連番＋短いスラッグで命名する：`NNN-短い題名.md`。
- **連番は削除・再利用しない**（履歴として残す）。却下・置換されても消さず、ステータスを更新する。
- 新しい決定が過去を覆す場合は、古い方のステータスを `置換済み（→ NNN）` にし、
  新しい方に背景と「置き換えた ADR」を書く。**過去の本文は書き換えない**（当時の記録だから）。
- 実装が変わって過去 ADR の記述が現状と食い違うときは、本文ではなく**注記の追加**で示す。
- 迷ったら書く：後から「なぜこうなっているのか」を訊かれる決定は ADR 化する価値がある。
